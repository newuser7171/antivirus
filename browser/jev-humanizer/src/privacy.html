Your words stay yours.

Local first

Local edits use bundled English phrase rules. They work offline and need no key. They simplify wording but cannot freely paraphrase any text. Quotes, links and code are skipped by these rules. Inspect every suggestion, especially specialized or sensitive writing.

Jev checks

Only “Ask Jev to choose” sends data: your original text, the available drafts and selected tone go directly to https://api.typesafe.ai/v1/systemone. Your personal TypeSafe API key is sent to that service in an authentication header. No backend or analytics service is used by this extension.

TypeSafe’s processing, retention and account terms apply. The extension cannot control what the provider retains. Do not send information you are not permitted to disclose. Consent is required for each check. Cancelling a request does not guarantee that the provider stopped processing it.

Keys and drafts

The extension does not save your text or API key to local storage, sync or logs. They exist in the open extension page’s memory and are cleared when it closes. Clear everything removes the visible text, key and results. Copying a draft places it on your operating system’s clipboard.

Selected webpage text

Use selected text reads only the active page’s selection when clicked. It does not scan pages automatically or read full pages, password fields, account cookies or browsing history. Some browser pages and frames are inaccessible; paste text instead. The extension never modifies or submits webpage forms.

Optional browser AI

If Chrome exposes its Rewriter API, the extension can ask its local model for a draft. This is separate from Jev. Your browser may download a large model after you opt in. The browser controls that download and availability. This feature is not available in Firefox or Android. No additional writing-provider API key is required.

What scores mean

Jev selects from existing candidates and estimates whether each preserved the meaning. Recommendations require at least 0.55 choice confidence and 0.90 estimated meaning preservation for a changed draft. These are product thresholds, not empirically validated guarantees. Jev does not generate rewrites. You can always inspect candidates manually. There is no AI-detector score or detector-bypass guarantee.
