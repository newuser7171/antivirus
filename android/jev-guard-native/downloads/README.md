# Jev Guard 0.2.0

[Download signed APK](Jev-Guard-0.2.0.apk?raw=true)

Install over the native 0.1.0 app (ai.jevguard); signing certificate is unchanged. Rescan old APK reports to collect content evidence, then choose Scan with Jev. A TypeSafe API key is required. VirusTotal is optional.

Build and device tests: https://github.com/newuser7171/antivirus/actions/runs/35501664385

This ports the desktop Jev verdict/severity/indicator approach to sampled Android static evidence. Live Jev accuracy has not been benchmarked. No automatic quarantine or deletion.
